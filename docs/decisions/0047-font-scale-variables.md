# 결정 0047: 글씨 크기 변수와 구역 — 모든 글자를 한 기준값(--fz)에서 (이슈 #151)

- 날짜: 2026-11-18
- 상태: 확정
- 관련 이슈: #151 (셸 개편 S1-2, 순서표 #144)
- 기준: 디자인 규칙 v0.4.6 02절 "글씨 크기 단계", 시안 "v0.4.3 · 아주 크게 150%"

## 배경

1/1에 "글씨 크기"(작게 90% ~ 아주 크게 150%) 화면이 들어온다. 나중에 넣으면 화면마다 고정 px을 다시 고쳐야 해서 깨지기 쉽다(결정 0046의 메뉴와 같은 이유). 이번에는 **뼈대만** 만든다: 모든 글자가 한 기준값 `--fz` 를 따르게 한다. 글씨 크기를 고르는 화면 · 저장 · "휴대폰 설정 따르기" · 알리기 카드, 그리고 130% 이상에서 화면 내용 배치를 바꾸는 일은 S7이다.

## 결정

1. **화면에서 고르는 값은 `--fz` 하나**(작게 0.9 · 보통 1 · 크게 1.15 · 더 크게 1.3 · 아주 크게 1.5, 기본 1)이고, 나머지는 `:root` 에서 거기서 계산한다(`tokens.css`).

   | 변수    | 식                       | 쓰는 곳                                                          |
   | ------- | ------------------------ | ---------------------------------------------------------------- |
   | `--fz`  | (고르는 값)              | 본문 · 판정 · 숫자 · 버튼 · 시트 · 알림 (14px 이상)              |
   | `--fzc` | `min(--fz, 1.3)`         | 배지 · 하단 탭 글자 (130% 상한)                                  |
   | `--fz2` | `min(--fz, 1.15)`        | 13px 이하 글자 — 축 · 범례 · 눈금 · 메모 (115% 상한)             |
   | `--fh`  | `max(1, min(--fz, 1.3))` | 버튼 · 입력칸 · 목록 줄 높이 (130% 상한, 작게에서도 줄이지 않음) |

   크기는 모두 "기준 px × 단계"다(화면 확대 아님). 간격 · 아이콘 · 그래프 높이 · 화면 폭은 그대로다.

2. **12 · 13px 글자는 작게(90%)에서도 12px 밑으로 줄이지 않는다**(`max(12px, …)`, 11/17 결정). 하단 탭 글자(`text-12`)도 마찬가지라 작게에서 12다 (이슈 본문 표의 "탭 10.8"은 검토에서 정정되었다).
3. **글자 토큰은 `@theme inline` 에 둔다 — "상속 함정" 피하기.** 일반 `@theme` 에 `--text-17: calc(17px * var(--fz))` 를 두면 Tailwind 가 그 값을 `:root` 변수로 내보내고(`font-size: var(--text-17)`), 변수 안의 `var(--fz)` 는 `:root` 에서 이미 계산된 값이 아래로 내려온다. 그러면 고정 · 상한 구역에서 `--fz` 를 되돌려도 글자가 바뀌지 않는다. `@theme inline` 은 값을 유틸리티에 그대로 적어(`.text-17 { font-size: calc(17px * var(--fz)) }`) **쓰는 자리에서** 계산하게 한다. 빌드된 CSS 에서 확인했다.
4. **구역은 쓰는 변수 넷을 모두 다시 정의한다**(시안 `data-fzfix` · `data-fztab` 와 같은 방식). 파생 변수가 `:root` 에서만 계산되어 내려오므로 `--fz` 만 바꾸면 `--fzc` · `--fz2` 가 따라오지 않기 때문이다.
   - `.fz-fixed`(= `data-fzfix`): 넷 모두 1 — **100% 고정**. 휴대폰 머리 줄 · 데스크톱 메뉴 줄(`SiteHeader` 머리 줄) · 선택 바(`SelectionBar`). 390 폭에서 작물 · 지역 칩이 17/700으로 이미 꽉 차 있어서다.
   - `.fz-cap`(= `data-fztab`): `--fz`·`--fz2` 를 `--fzc` 로, `--fh` 를 1로 — **130% 상한**. 하단 탭바(`TabBar`)와 배지 모양 글자 상자(`ui/Badge`, `ui/StatusBadge`, `ui/status.ts` 의 `STATUS_BADGE` 를 쓰는 곳 등). **배지 · 탭 안의 작은 글자(12 · 13px)는 115% 가 아니라 130% 상한**이다(규칙: 탭 · 배지는 130%).
   - `.fz-follow`: 고정 구역 안에 있지만 글씨 크기를 따라야 하는 곳(지역 · 작물 고르기 팝오버)이 화면 전체 값으로 되돌릴 때 쓴다. `:root` 가 `--fz-page` 등 복사본을 만들어 두고(구역이 덮어쓰지 않는다) `.fz-follow` 가 그것을 되돌려 준다. 고르기 판(`SelectionPanel`, 포털)과 알림 띠는 구역 밖이라 그대로 따른다(규칙의 "시트 · 알림").
5. **높이는 `fh-<px>` 유틸리티**(`min-height: calc(<px> * 1px * var(--fh))`)로 쓴다. 글자가 커져 잘리지 않도록 `height` 가 아니라 `min-height` 다. `--fz` 1 에서는 기존 `h-N` 과 같은 크기라 화면이 그대로다(기존 화면 시험이 그대로 통과한다). 누르는 곳 44 이상은 늘 지켜진다(`--fh` ≥ 1). 고정 구역 안의 높이는 `--fh` 가 1이라 바꾸지 않았다. 차트 · 게이지 · 눈금 글자 상자처럼 높이가 고정된 곳은 이번에 키우지 않는다(아래).
6. 하단 탭바 줄 높이는 고정(`leading-3.5`, 14px)이라 130%(15.6px)에서 글자가 잘렸으므로 배수(`leading-title`, 1.15)로 바꿨다. 탭바 높이 54는 그대로다.
7. 정의되지 않은 토큰 `text-11`(`FarmScreen`)은 하한 12에 맞춰 `text-12` 로 고쳤다.

## 알려진 한계 (S7 재료)

- **150%에서 화면 내용이 조금 넘치는 곳**은 이번 범위 밖이다(물 판정 카드 숫자 셋 세로, 종합표 막대를 아래 줄로, 온도 카드 쌓기, 로그인 시트 설명 내리기 등 130% 이상 배치 바꿈은 S7). 셸(탭바 · 머리 줄 · 데스크톱 메뉴 줄 · 선택 바 · 더보기)은 150%에서도 넘치지 않으며 `e2e/font-scale.spec.ts` 가 지킨다. 150%에서 새로 넘치는 화면 목록은 이 이슈(#151)의 PR 본문에 있다.
- 고정 높이 글자 상자(차트 눈금 · `NowCard` 의 `h-9.5` · `h-8` 눈금 글자 등)는 키우지 않았다.
- 글씨 크기를 고르는 화면이 없으므로 `--fz` 는 항상 1이다. 시험은 `<html>` 의 `--fz` 를 직접 바꿔서 한다.
- 다크 모드 · 색은 건드리지 않았다.

## 버린 안

- **`@theme` 그대로 두고 구역마다 모든 글자 변수를 다시 정의하기**: 글자 토큰이 20여 개라 구역마다 모두 적어야 하고, 하나라도 빠지면 조용히 어긋난다.
- **`data-fz` 속성에 단계별 값을 직접 쓰기(시안 방식)**: 시안은 화면 한 장이라 가능하지만, `--fz` 하나만 바꾸면 파생 변수가 따라오게 해야 시험과 S7 화면이 단순하다.
- **화면 확대(`zoom`)**: 간격 · 아이콘 · 폭까지 커져 규칙("기준 px × 단계")에 어긋난다.
