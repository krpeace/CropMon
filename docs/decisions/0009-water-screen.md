# 0009. 물 화면 본문 (물5)

- 날짜: 2026-10-25
- 상태: 확정

## 결정

- **시안 그대로 옮긴다:** 기준 날짜 줄, ① 지금 토양 상태, ② 앞으로 3일, ③ 작기 돌아보기와 월별 요약. 색·글자 크기·모서리는 토큰으로만 쓴다 (`--text-verdict`, `--text-20`, `--grid-wide` 460, `--grid-day` 170을 더함).
- **시안에 없어 더한 것:** ② 위쪽에 관수 필요 예상일·권장 관수량 한 줄(오늘만), 마지막 참고일 칸(흐리게, "참고"), 재배 방식 칩 줄(기준 날짜 줄 아래).
- **판정 문구는 화면 규칙으로 둔다** (결정 0002·0003의 "나중에 정할 것"을 닫음). 계산이 아니라 DB가 준 상태와 "관수 필요까지 며칠"로 문장을 고르는 표시 규칙이다 (`src/domain/water-verdict.ts`).
  - 오늘: 요약 표의 출발 상태와 관수 필요 예상일(중심)을 쓴다. 그래서 문구와 예상일이 서로 어긋나지 않는다.
  - 지난 날: 그날 관측 상태와 다음 3일(관측, 없으면 예보)의 상태로 고르고, 지난 말로 쓴다.
  - 휴면기·작기 아님: 다음 작기 시작일을 알려 주고, 관수 필요 예상일은 보이지 않는다.
- **기준 날짜 `&d=`**: 작기 자료 첫날 ~ 어제. 오늘이면 주소창에 붙이지 않는다. 그래프를 누르거나 날짜 칸으로 고른다.
- **발표 회차 `&run=02|17`**: 오늘 받은 회차 중에서만 고른다. 없으면 가장 최근 회차. 아직 받지 않은 회차는 흐린 글자로 둔다.
- **월별 요약은 화면에서 더한다.** 일별 값을 달마다 더하기만 하는 표시용 합계라 계산 금지 규칙(CLAUDE.md 1번)의 예외로 둔다(2026-10-25 사용자 승인). 나중에 DB에 넣어도 표 모양은 그대로다.
- **그래프는 서버에서 SVG로 그린다.** 누르면 그날로 가는 부분과 날짜 고르기만 브라우저 코드다.
- **화면 테스트는 가짜 Supabase로 한다** (`e2e/fake-supabase.mjs`). 진짜 DB·키 없이 자료가 있는 화면, 휴면기, DB 오류를 모두 열어 본다. CI 도 build 때 이 주소를 쓴다.

## 남은 것

- 시안의 "올해 vs 평년" 비교선과 예상 점선은 평년 자료가 생기면 더한다.
- 종합 화면·지역 칩 점 색의 DB 연결은 첫1·기5에서 한다.
