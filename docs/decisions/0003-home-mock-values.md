# 0003. 종합 화면 숫자는 시안 값을 고정 값으로 넣는다

- 날짜: 2026-10-23
- 상태: 물 판정 부분은 대체됨 (0011). 온도·햇빛 예시 값은 "예시" 표시와 함께 남음

## 결정

- 종합 화면의 물·온도·햇빛 카드, 전국 표의 숫자는 시안(기준일 2026년 8월 12일)에 나온 값을 그대로 고정 값으로 넣는다.
- 종합 화면은 5초마다 지역·작물 20가지를 돌기 때문에, 20가지 모두의 값을 넣는다 (`src/mocks/home.ts`).
- 값은 시안을 저장소 밖에서 한 번 열어 읽었다. 시안의 계산 코드는 저장소에 넣지 않았다 (CLAUDE.md 규칙 1).
- 예시 값은 DB가 줄 법한 모양(판정 상태, 부족한 물, 관수 시작점, 뿌리층 전체, 판정 문구, 앞으로 3일 상태, 적산온도·적산일사)으로 두고, 화면 문구("부족한 물 31 mm / 관수 시작점 35 mm")와 게이지 길이는 `src/services/home.ts`가 만든다. Supabase 로 바꿀 때는 이 파일만 고친다.
- 판정 문구("오늘은 괜찮아요, 내일 물 주세요")와 카드 색은 지금은 예시 값에 들어 있다. DB(cropwater)가 줄지, 화면 쪽 규칙으로 둘지는 0002 의 "나중에 정할 것"에 그대로 남긴다.
- "오늘은 여유인데 내일 관수 필요"를 배지로 미리 알려 주는 것은 두 상태를 보여 주는 방법이라 화면 쪽 규칙(`todayBadge`, `src/domain/water-status.ts`)으로 둔다.

## 나머지 화면

- 물·온도·햇빛·내 농장 화면 본문의 예시 값을 같은 방식으로 넣을지는 아직 정하지 않았다.
