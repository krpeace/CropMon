# 0028: 누르는 곳 44px 이상, 화면 오류 문구에서 "DB" 빼기 (이슈 #15)

- 날짜: 2026-10-29
- 상태: 확정

## 배경

시안 규칙은 "누르는 곳 44px 이상"이다. 폭 390 에서 재 보니 소개 버튼(89×32), 재배 방식 칩(높이 38), "02시"(60×32), "미리보기"(55×19), 토양 버튼과 토양 12종 목록 칩(높이 40), 온도·햇빛 지점 줄(36), 내 농장 사과·배추(42)가 작았다. 또 화면 오류 문구에 "DB에서 … 읽지 못했어요"가 있었다(프로젝트 규칙 7: 쉬운 말).

## 결정

1. **두 가지 방법으로 지킨다.**
   - **`hit-44` (tokens.css 의 유틸)**: 보이는 모양은 그대로 두고 `::after` 로 누르는 영역만 44×44 이상으로 넓힌다. 시안 간격이 정해져 있고 키우면 화면이 길어지는 곳에 쓴다. 재배 방식 칩, "02시", "미리보기", 온도·햇빛 지점 줄, 내 농장 사과·배추. 이웃과는 맞닿기만 하고 겹치지 않는다(줄 36+8, 칩 38+6 모두 44 간격).
   - **`min-h-11` (보이는 높이를 44로)**: 키워도 모양에 영향이 거의 없는 곳. "CropMon 소개", "계산에 쓴 토양" 버튼, 그 목록의 토양 12종 칩. 이 곳만 보이는 높이가 조금 커진다.
   - `hit-44` 를 쓸 요소에 `::after` 가 이미 있거나 `overflow: hidden` 에 잘리면 쓰지 않고 다른 방법을 정한다.
2. **실제로 눌리는 영역으로 잰다 (`e2e/tap-targets.spec.ts`).** 보이는 크기(getBoundingClientRect)로 재면 `hit-44` 로 넓힌 영역이 잡히지 않고, 눌리지 않는 크기도 통과해 버린다. 요소 가운데에서 위아래(너비 44 미만이면 좌우도) 21px 떨어진 점을 `elementFromPoint` 로 확인한다. 펼쳐야 보이는 토양 목록은 연 상태로 한 번 더 잰다. 작물·지역 고르기 창은 판으로 바뀔 예정이라 이번 검사에서 뺀다. 어쩔 수 없는 요소는 `EXCEPTIONS` 에 이유와 함께 적는다(지금은 비어 있음).
3. **화면 오류 문구에서 "DB"를 뺀다.** "DB에서 자료를 읽지 못했어요" → "자료를 불러오지 못했어요"(물·온도·햇빛은 "물 자료를", "온도 자료를", "햇빛 자료를"). 농업인에게 "DB"는 어려운 말이다. 개발용 오류 기록과 코드 주석의 "DB"는 화면에 나오지 않아 그대로 둔다. e2e 오류 테스트 3곳에 `not.toContainText("DB")` 를 넣어 다시 들어오지 않게 막는다.
