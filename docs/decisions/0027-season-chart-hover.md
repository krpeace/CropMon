# 0027: 작기 돌아보기 그래프 따라 보기 (이슈 #46)

- 날짜: 2026-10-29
- 상태: 확정

## 배경

물 화면 ③ 작기 돌아보기 그래프는 마우스를 올리면 "+" 커서만 바뀌고 아무 값도 보이지 않았고, 누르면 바로 그날 물 화면으로 넘어갔다. 그날 값을 보려면 일단 이동해야 했다.

## 결정

1. **데스크톱과 휴대폰의 동작을 다르게 한다.**
   - 마우스: 올리면 세로 안내선·점·값 상자가 따라오고, 벗어나면 사라진다. 누르면 지금처럼 그날로 간다.
   - 휴대폰: 올리기가 없으므로 **누르기가 값 보기를 맡는다.** 누르고 끌면 따라오고, 손을 떼면 그 자리에 고정된다. 이동은 상자 안 "이 날 보기 ›" 를 눌러야 한다. 값을 보려던 탭이 실수로 다른 날로 넘어가는 것을 막기 위해서다.
   - 위아래 쓸기는 그대로 화면 스크롤이다 (`touch-action: pan-y`). 쓸기가 시작되면 누르기 전 상태로 되돌린다.
2. **상태는 DB가 준 `status` 를 그대로 보여 준다.** 화면에서 Dr·RAW 를 비교해 판정하지 않는다 (프로젝트 규칙 1).
3. **숫자 자릿수는 월별 요약 표와 같게** 정수로 반올림하고 ` mm` 를 붙인다 (`monthlySummary` 와 같은 규칙). 값이 없으면 "자료 없음", 휴면기 날의 ETc 는 사과 "휴면기"·배추 "작기 아님".
4. **누르기와 따라 보기가 같은 함수로 날짜 칸을 찾는다.** `ChartClick` 안에 있던 "x 위치 → 날짜 칸" 계산을 `season-chart.ts` 의 `dayIndexAt` 으로 옮겼다 (단위 테스트 있음). `ChartClick` 은 지우고 `ChartHover` 로 바꿨다.
5. **결정 0009 의 "브라우저 코드는 누르기와 날짜 고르기만" 을 "누르기·따라 보기와 날짜 고르기" 로 넓힌다.** 그래프 선·격자는 여전히 서버에서 SVG 로 그리고, 브라우저는 그 위에 안내선·점·값 상자만 겹친다. 새 라이브러리는 쓰지 않았다.
6. **안내 문구는 기기에 맞게 두 벌**을 CSS(`@media (pointer: coarse)`)로 고른다. 서버에서는 기기를 알 수 없어서다.
7. **값 상자는 가운데를 넘으면 안내선 왼쪽으로 뒤집히고**, 가장자리에서는 카드 밖으로 나가지 않게 멈춘다.

## 남은 것

- 온도·햇빛 그래프와 작물 공통 그래프에도 같은 따라 보기를 쓰기 (`ChartHover` 재사용)
- 그래프에서 ←→ 키로 안내선 옮기기 (지금 키보드는 기준 날짜 줄을 쓴다)
- 일별 ETo·ETc 를 정수로만 보여 주는 점은 월별 표와 맞추기 위한 선택이다. 소수 첫째 자리가 필요하면 표와 함께 바꾼다.
