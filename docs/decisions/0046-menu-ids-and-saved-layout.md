# 결정 0046: 메뉴 고정 ID와 설정값 — 탭을 설정값에서 그린다 (이슈 #145)

- 날짜: 2026-11-18
- 상태: 확정
- 관련 이슈: #145 (셸 개편 첫 이슈, 순서표 #144)
- 이어받는 결정: 0026(휴대폰 하단 탭바). 0026의 "항목·순서·주소·아이콘은 `TABS`" 부분을 이 결정이 대신한다.

## 배경

탭이 `pages.ts` 의 `TABS` 에 고정돼 있었다. 회원제(2027-01-01)까지 메뉴가 늘고, 사용자가 메뉴를 켜고 끄고 순서를 바꾸는 "화면 구성"이 들어온다. 탭을 나중에 설정값으로 바꾸면 화면이 깨지므로, 셸 개편의 첫 이슈에서 뼈대를 먼저 놓는다. 이번에는 뼈대만 만들고 화면 구성 화면은 만들지 않는다.

## 결정

1. **메뉴 사전은 `src/domain/menus.ts` 한 곳.** ID·이름·주소·상태(운영/준비 중)를 가진 순수 함수 모듈이다. `TABS` 는 없앤다. 아이콘은 화면 쪽(`pages.ts` 의 `MENU_ICON`)에 둔다.
2. **ID 는 저장값이 되므로 고정한다.** `home` 종합 · `water` 물 · `temp` 온도 · `sun` 햇빛 · `outlook` 관측 · `price` 시세 · `farminfo` 농사정보 · `pest` 병해충 · `soil` 토양 · `diary` 일지. 이름은 바꿔도 ID 는 바꾸지 않는다. 기존 주소(`/water`, `/temperature`, `/sunlight`, `/soil`, `/market`)는 공유된 링크가 있어 그대로 두고, 새 쪽은 `/outlook` `/farminfo` `/pest` `/diary`, 더보기는 `/more` 로 한다.
3. **설정값 = 메뉴 ID 순서 + 끈 메뉴 목록.** 기기(`localStorage`) 키 `cropmon-menus`, 값 `{"v":1,"order":["home","water",…],"off":["temp"]}`.
   - 없거나 JSON 이 아니거나 모양이 틀리거나 **모르는 판 번호(`v`)** 이면 기본값으로 동작한다. 읽기만 하고 덮어쓰지 않는다 (이 PR에는 쓰는 코드가 없다).
   - 설정값에 없는 새 ID 는 끝에 "켬"으로 붙이고, 사전에서 사라진 ID 는 무시한다. 종합은 꺼짐으로 저장돼 있어도 켠 것으로 본다.
   - 회원 계정에 저장하는 것은 나중 이슈다. 비회원은 기기에만 저장한다. 저장소가 막혀 있으면(사생활 보호 모드 등) 기본값으로 동작한다.
4. **기본 순서**는 종합 · 물 · 온도 · 햇빛 · 관측 · 시세 · 농사정보 · 병해충 · 토양 · 일지. 켠 메뉴 가운데 **위에서 4개가 하단 탭**이고, 켠 메뉴가 4개보다 적으면 탭도 그만큼이다. 준비 중 메뉴가 탭으로 올라오는 것(온도를 끄면 관측이 탭 4번)은 규칙대로 둔다.
5. **`resolveMenus(saved | null)`** 이 `tabs`(하단 탭) · `more`(더보기 목록, 종합이 맨 위) · `desktop`(데스크톱 메뉴 줄) · `hiddenCount`(끈 메뉴 수, 종합 제외)를 돌려준다.
6. **데스크톱 메뉴 줄은 순서 고정(기본 순서)이고 끈 메뉴만 숨긴다.** 순서 바꾸기는 휴대폰 탭과 더보기에만 반영한다.
7. **하단 탭바 = 탭 4개 + 더보기(맨 오른쪽 고정)**, 높이 54(시안 v0.4, `--tabbar-h` 66 → 54), 캡슐 반지름 27·탭 반지름 23(`--radius-tabbar`, `--radius-tab`). 탭에 없는 화면을 보고 있으면 켜진 탭이 없고, 더보기 탭은 `/more` 에서만 켜진다. 두 `nav` 의 `aria-label` "메뉴"는 그대로 둔다(0026).
8. **더보기 화면(`/more`)**: 제목 + 서비스 메뉴 목록(맨 위 종합, 켠 메뉴, 준비 중은 꼬리표). 끈 메뉴가 있으면 맨 아래 "숨긴 메뉴 n개 · 화면 구성에서 다시 켜기" 한 줄이며, 화면 구성 화면이 생기기 전이라 눌러도 이동하지 않는다(`aria-disabled`). 지역·작물 고르는 줄과 자료 상자는 없고, 고른 지역·작물(`?st=&crop=`)은 목록 링크에 이어 붙는다. 공지·문의·FAQ·약관과 화면 구성·글씨 크기·다크 모드 자리는 이번 범위 밖이다.
9. **"도매시장 → 시세"는 메뉴 이름·쪽 제목·메타 제목만.** 준비 중 본문의 설명 문장("도매시장에 들어온 양(반입량) 흐름" 등)과 정보 시트의 "도매시장 가격(aT)"은 시장 자체를 가리키는 말이라 그대로 둔다. 종합 화면의 카드 이름은 다음 이슈(S6)에서 바꾼다.

## 알려진 한계 (일부러 이번에는 두는 것)

- **첫 그리기는 기본값, 기기 저장값은 화면이 뜬 뒤 적용한다.** 서버는 `localStorage` 를 모르므로, 저장값이 있는 사람은 탭이 한 번 바뀌어 보일 수 있다. 지금은 설정값을 바꾸는 화면이 없어 저장값을 가진 사람이 없다. 다크 모드의 `THEME_SCRIPT` 처럼 그리기 전에 맞추는 방식은 탭 전체를 서버에서 못 그리는 문제가 있어, 화면 구성 화면(S5)을 만들 때 다시 판단한다.
- **데스크톱 1440에서 메뉴 10개**는 시안 수치(글자 17 · 좌우 15 · 간격 2, 1280 미만은 글자만 · 좌우 11 · 간격 0)로 한 줄에 들어간다. 시험(`e2e/more.spec.ts`)이 한 줄에 들어가는지와 글자가 12px 아래로 내려가지 않는지를 지킨다.

## 버린 안

- **저장값을 서버(쿠키)로 읽어 첫 그리기부터 맞추기**: 회원제 전에는 계정이 없어 기기 값뿐이고, 쿠키를 쓰면 쪽마다 요청 단위 렌더링이 되어 캐시 구조(결정 0038)와 부딪힌다.
- **`TABS` 를 두고 설정값으로 덮어쓰기**: 메뉴가 둘로 갈라져(고정 목록과 설정값) 화면 구성 화면이 생길 때 다시 깨진다.
