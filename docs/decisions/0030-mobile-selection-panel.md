# 0030: 휴대폰 작물·지역 선택 줄을 한 줄로, 고르기를 버튼 아래 펼침 판으로 (이슈 #15)

- 날짜: 2026-10-29
- 상태: 확정 (시안 v0.3.0 의 "모바일은 하단 시트"를 사용자 결정으로 바꿈)

## 배경

1. 선택 줄의 작물·지역 버튼은 `flex-wrap` 이라, 합친 너비가 줄 폭보다 넓으면 지역 버튼이 아래 줄로 내려갔다. 폭 360 에서는 늘, 390 에서도 "작물 공통 · 안동"처럼 흔하게 두 줄이 되어 선택 줄 높이가 64 에서 120 이 되었다.
2. 폭 1024 미만에서 작물·지역 버튼을 누르면 화면 아래에서 올라오는 시트가 떴다. 작물은 3개뿐이라 위에서 누른 버튼과 아래 목록이 멀었고, 지역 시트는 검색칸이 위쪽에 있어 키보드가 올라오면 목록이 아주 좁아졌다.

## 결정

1. **선택 줄은 폭 1024 미만에서 항상 한 줄, 두 버튼이 너비를 반씩** (`flex-nowrap`, 간격 8, 버튼 `flex-1 basis-0 min-w-0`). 줄이는 순서: 작물 버튼은 이름(사과·배추·작물 공통)을 지키고 회색 보조 글자를 `…` 로, 지역 버튼은 지점번호 → 지점 이름 순서로 줄인다. 지역 버튼의 "지역 ·" 은 핀 아이콘으로 바꾸고 화면 읽기용 글자(`sr-only`)는 남겨 버튼 이름("지역 · 춘천 101 …")이 그대로다. 상태 색 점은 선택 지역의 오늘 물 상태 정보라 그대로 둔다. 1024 이상은 지금 모양 그대로.
2. **고르기 시트 → 선택 줄 바로 아래 펼침 판.** 위쪽 = 선택 줄 아래 끝 + 8, 좌우 = 화면 가장자리 여백. 아래쪽 화면과 탭바는 덮개(`bg-scrim/28`)로 덮고 머리말은 덮지 않아 누른 버튼과 판이 이어져 보인다. 판이 열리면 뒤 화면 스크롤을 잠근다. 목록이 길면 판 안에서 스크롤하고 지역 검색칸은 맨 위에 고정한다.
3. **포털로 `document.body` 에 그린다 (`SelectionPanel`).** 머리말에는 `backdrop-filter`(`glass`)가 있어 그 안의 `position: fixed` 는 화면이 아니라 머리말 기준이 되고, 머리말(z-20) 안에서는 탭바(z-30)보다 위로 올라갈 수도 없다. 겹침 순서: 덮개 z-40, 판 z-45. 소개·로그인 창(z-40)과 판은 동시에 열리지 않는다.
4. **높이는 보이는 화면 기준.** 판 아래 끝이 `visualViewport.offsetTop + visualViewport.height − 12` 를 넘지 않게 한다. 아이폰은 키보드가 뜨면 `offsetTop` 이 생길 수 있다. 크기 변경(`resize`)과 `visualViewport` 변화 때 다시 잰다.
5. **스크롤 잠금은 `html` 과 `body` 둘 다**, 덮개에 `touch-action: none`, 판 안 목록에 `overscroll-behavior: contain`. 아이폰 사파리는 `body` 만 막으면 끌어서 스크롤이 될 때가 있다.
6. **닫는 방법**: 같은 버튼 다시 누르기, 덮개 누르기, "닫기", Esc, 항목 고르기, 머리말(로고·테마·로그인) 누르기(판이 먼저 닫힌다), 경로나 선택이 바뀔 때, 폭이 1024 이상이 될 때. 다른 버튼을 누르면 열린 판이 바뀐다.
7. **포커스**: 열리면 판 안의 "닫기" 로, 닫히면 연 버튼으로 돌려준다.
8. **휴대폰에서는 지역 검색칸에 자동 포커스하지 않는다.** 키보드가 바로 올라오면 대표 지점 목록이 가려진다. 사용자가 검색칸을 누르면 올라온다. 데스크톱은 지금처럼 자동 포커스한다.
9. **열림 상태는 `SelectionBar` 의 로컬 상태.** 이 선택 줄 안에서만 쓰고, 데스크톱 팝오버(`popover`)와 섞이지 않으며, 소개·로그인 창과 동시에 열리지 않아 전역(`SheetProvider`)에 둘 이유가 없다. 닫힘 판단은 효과(effect) 안에서 상태를 바꾸지 않고, 상태에 "연 때의 경로·선택"을 함께 적어 지금 값과 다르면 닫힌 것으로 계산한다. 그래서 `SheetKind` 에서 `"station" | "crop"` 과 하단 시트(`StationSheet`, `CropSheet`)를 지웠다.
10. 1024 이상 1280 미만의 지역 팝오버(`RegionPopover`)와 데스크톱 동작은 바꾸지 않는다.
