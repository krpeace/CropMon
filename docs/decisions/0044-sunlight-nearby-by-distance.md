# 결정 0044: 햇빛 미관측 지점의 대신 볼 지점을 거리순 실측 지점으로 추천

- 날짜: 2026-11-15
- 상태: 채택
- 관련 이슈: #78

## 배경

햇빛 화면(`/sunlight`)에서 일사를 재지 않는 지점(`kind === "notMeasured"`)을 열면 `NotMeasuredCard`가 항상 춘천(101)·안동(136) 두 곳만 고정으로 추천하고 있었다. 진도군(268)처럼 남해안·서해안 등 멀리 떨어진 지점에서는 가까운 실측 지점(예: 목포·완도)을 바로 눌러 볼 수 있어야 한다.

## 결정

1. **지점 사전(`src/infra/stations.ts`)에 위경도(`lat`, `lon`) 포함**: 화면을 그리기 전에 바로 거리순 정렬을 해야 하므로 DB `stations`를 별도로 묻지 않고 사전 SQL(`20261028030000_seed_stations_asos.sql`)의 105곳 위경도를 그대로 옮겨 `seed.test.ts`로 일치를 검사한다.
2. **안내용 순수 거리 정렬(`src/domain/nearby.ts`)**: `nearestStations`의 하버사인 거리 계산은 화면에서 대신 볼 관측소를 고르는 **안내용 거리 정렬이지 농업 계산이 아니다**. 외부 의존성 없이 `domain/` 순수 함수로 둔다.
3. **미관측 지점에서만 최근 실자료 1회 조회**: `services/sunlight.ts`의 `readMain`이 `notMeasured`를 반환할 때만 가까운 운영 지점 8곳을 `sun_daily`에서 `.in("stn_id", ...)`로 한 번(`stn_id` 1열, 최근 14일 `rs_cum_mj is not null`) 조회해 가까운 1~2곳을 고른다. `readMain`과 동일한 열(`rs_cum_mj != null`)을 기준으로 삼아 추천 지점을 눌렀을 때 다시 `"재지 않아요"`가 나오지 않도록 보장한다.
4. **폴백과 격리**: 후보 8곳 모두 자료가 없거나 조회가 실패하면 대표 10곳 중 `measuresSunlight === true`인 지점에서 거리순 2곳으로 대신하며, 화면은 멈추지 않는다. 측정 지점 화면과 종합 화면(`board.ts`, `home.ts`)은 추가 읽기가 없다.
5. **버튼 거리 표기**: 각 추천 버튼 아래 작은 글씨(`약 ○○km`)로 대략적인 거리를 함께 보여 주며 버튼 터치 높이(50px, 44px 이상)는 유지한다.
