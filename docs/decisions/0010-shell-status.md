# 0010. 공통 틀의 지역 칩 점 색과 관측 시각은 DB 값 (기5)

- 날짜: 2026-10-25
- 상태: 확정

## 결정

- **지역 칩 점 색 = 지점의 오늘 물 판정.** 물 화면 ①과 같은 기준이다: 그 지점·작물의 기본 재배 방식 조건으로
  1. 최신 회차(서버 수집, 실패 제외)의 출발 상태(`water_outlook_summary.status_start`),
  2. 회차가 없으면(예보는 춘천만 받음) 최근 7일 안의 마지막 관측 물수지 판정,
  3. 둘 다 없으면 회색 점과 "자료 없음".
- **한 번에 네 번 읽는다:** 기본 조건 20개, 최근 회차 40개, 그 회차들의 요약, 최근 7일 물수지. 지점마다 따로 묻지 않는다.
- **헤더는 5분 동안 같은 값을 쓴다** (`use cache`, 다시 읽기 300초). 헤더는 모든 쪽에 나오고 판정은 하루 두 번 바뀌기 때문이다. 배포용으로 만들 때(build) 미리 읽지 않고 첫 요청 때 읽는다(`connection()`), 그래야 build 때 DB 에 닿지 못해도 "자료 없음"이 5분 동안 남지 않는다.
- **색만으로 말하지 않는다:** 칩마다 화면 읽기 도구용 판정 이름("춘천 주의", "태백 자료 없음")을 붙인다.
- **온도·햇빛 자료 상자 갱신 =** 그 지점의 마지막 `weather_daily` 받은 시각과 관측일 ("10월 25일 02:20 (10월 24일까지 관측)"). 시안 예시 값("8월 12일 17:42")은 사실과 달라 지웠다(규칙 6). 햇빛을 재지 않는 지점은 그대로 "자료 없음".
- **지점 목록은 고정 사전으로 둔다** (`src/infra/stations.ts`). 주소창을 읽을 때 바로 써야 해서 DB 를 묻지 않는다. DB 사전 자료와 번호·이름·순서가 같은지 테스트가 검사한다.
- **버전 표시**는 그대로(v0.0.0). 일정대로 11/05 시범 사용 때 v0.1.0 으로 올린다.

## 남은 것

- 종합 화면(물·온도·햇빛 카드, 전국 표)은 아직 예시 값이다. 첫1에서 이 읽기(`getStationStatuses`)를 넓혀 쓴다. 그때까지 헤더 점 색(실제)과 종합 화면 숫자(예시)가 서로 다를 수 있다.
- 내 농장 미리보기의 자료 상자는 미리보기 예시 값 그대로다.
