# 0001. 서비스 이름을 CropMon 으로 바꾼다

- 날짜: 2026-10-23
- 상태: 확정

## 결정

- 서비스 표시 이름은 CropMon, 패키지 이름은 `cropmon` 으로 한다. GitHub 저장소 이름도 CropMon 이다.
- 부제는 "농업 데이터와 내 농장 기록으로 작물 재배 판단을 돕는 서비스"로 한다.
- 계산을 맡는 별도 저장소 `cropwater` 는 이름을 바꾸지 않는다.
- CLAUDE.md 는 "공통 규칙"과 "CropMon 전용 규칙"으로 나눈다. 나중에 공통 규칙만 회사 공통 틀로 떼어 쓰기 위해서다. 규칙 내용과 번호는 바꾸지 않았다.
