# 0016. 햇빛 화면 본문 (온1)

- 날짜: 2026-10-25
- 상태: 확정 (이슈 #21, 결정 0013 의 화면 쪽)

## 결정

- **시안 그대로 옮긴다:** 올해 쌓인 햇빛 카드, 적산일사 누적 그래프, 아래 두 칸(월별 햇빛 | 지역 비교), 일사를 재지 않는 지점 화면.
- **평년 표기**는 DB 의 `normal_from`–`normal_to` (지금 2016–2025). 자료 상자 출처에도 붙인다.
- **평년 대비 %** = 마지막 관측일 `rs_cum_mj ÷ rs_normal_cum_mj`. **월별 막대** = 그 달 `rs_day_mj` 합과 `rs_normal_day_mj` 합(마지막 관측일까지), 가장 적은 달은 평년 대비 %가 가장 낮은 달. 모두 표시용 순수 함수(`src/domain/sun.ts`)로 둔다 (결정 0009 의 표시용 합계와 같은 예외).
- 마지막 달은 막대 아래 설명에 "10월은 24일까지".
- **"햇빛을 재지 않는 지점"은 DB 기준:** `sun_daily` 에 그 지점 줄이 없을 때. `src/infra/stations.ts` 의 `measuresSunlight`(태백 false)는 시안에서 온 값이고 10/25 수집에서 태백에도 일사 자료가 있었다. 이번에는 화면 판단만 DB 기준으로 바꾸고, `measuresSunlight` 를 쓰는 곳(종합 카드·자료 상자)은 그대로 둔다 — 정리는 별도 이슈.
- 재지 않는 지점의 "가까운 지점" 버튼은 시안처럼 춘천·안동 고정.
- **지역 비교 읽기:** 온도와 같다 (10곳 한 번에, 어제 날짜, 없는 지점만 최근 14일 보충). 자료가 없는 지점은 "자료 없음". 눈금은 시안 그대로 85~110%, 세로선 = 100%.
- 누적 그래프 카드는 온도 화면 것을 제목만 바꿔 같이 쓴다.

## 남은 것

- 휴대폰 폭(390)에서 월별 막대 위 % 글자 10개가 거의 붙어 보인다 (넘치지는 않음). 모바일 배치 때 다듬는다.
- `measuresSunlight` 정리 (태백): 종합 카드·자료 상자를 DB 기준으로.
