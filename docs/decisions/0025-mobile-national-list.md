# 0025: 휴대폰 전국 종합 목록(1b)과 '주의' 주황 테두리 (이슈 #15)

- 날짜: 2026-10-29
- 상태: 확정

## 배경

휴대폰(폭 1024 미만)에서는 "전국 물·기상·생육 종합" 표가 숨겨져 있었다. 시안 `종합표 휴대폰 390 배치안`의 1b(항목 바꾸기형)를 넣는다. 함께, 물 판정 '주의'가 작물 공통 '보통'과 같은 초록이라 헷갈려 주황 테두리로 바꾼다.

## 결정

1. **1b를 고른 이유**: 대표 10곳을 세로로 한 화면에서 비교할 수 있다. 지점·오늘 배지는 늘 보이고 셋째 칸만 탭(물·3일·온도·햇빛)으로 바뀐다. 기본 탭은 "물".
2. **폭 기준 1024px**: 이상은 지금 데스크톱 표 그대로, 미만은 1b 목록. 태블릿 전용 배치는 이번 범위가 아니다.
3. **탭 기억**: `localStorage` `cropmon-national-tab`. 저장소가 막혀 있으면 이번 화면 동안만 메모리에 둔다.
4. **새 계산 없음**: `HomeRow` 에 `leadDays`·`sunPct` 두 숫자만 더했다(DB 값 그대로). 막대 폭 변환은 화면 전용 `national-list.ts`.
5. **'주의' 주황 테두리를 사이트 전체에 적용**: 배지는 투명 바탕 + 주황 글자 + 주황 테두리 1.5px, 점은 속 빈 주황 테두리. 다른 상태 색은 그대로.
6. **토큰 이름 정리**: 초록 `caution-*` 는 '주의'뿐 아니라 작물 공통 '보통(fair)'·내 농장 ok도 썼다. '주의'만 바꾸려고 `ok-*` 로 이름을 바꿨다(값 그대로).
7. **'주의' 카드는 흰 바탕**: 시안에 없어 정했다. 주황 테두리 배지와 겹쳐 보이지 않게 한다.
8. **'주의' 게이지·막대는 주황 꽉 채움**: 막대는 속을 비울 수 없다(시안 1b 그대로). 그래서 `STATUS_FILL` 을 따로 만들었다.
9. **시안 문구 하나를 뺀다**: 작물 공통 아래의 "휴면기가 없어요"는 작물 공통에 12~2월 '겨울철'이 있어 사실과 다르다.
