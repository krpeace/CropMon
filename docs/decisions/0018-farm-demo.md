# 0018. 내 농장 데모 화면 (정적 미리보기)

- 날짜: 2026-10-26
- 상태: 확정 (이슈 #31)

## 배경

- "내 농장" 화면은 로그인 후 사용자 본인의 밭 주소, 토성, 작물, 스마트팜 CSV 기록을 기반으로 맞춤형 물 판정 및 영농 보고서를 제공하는 회원제 기능이다.
- 정식 서비스는 2027년 1월 1일 오픈 예정이며, 그전까지는 디자인 시안(`CropMon 프로토타입.dc.html`)의 모양과 동작을 사용자에게 미리 보여 주는 정적 데모 화면으로 제공한다.

## 결정

- **계산 없이 표에서 읽기만 한다:**
  - 시안의 물수지 계산 흉내를 클라이언트 코드에 복제하지 않고, 일회성 스크립트로 240개 조합(`지점 10 × 작물 2 × 토성 12`)의 계산 결과를 미리 뽑아 `src/mocks/farm.ts` (`FARM_SAMPLES`)에 정적 상수로 둔다.
  - 화면 클라이언트 컴포넌트(`FarmScreen.tsx`)는 상태(주소, 토성 번호, 작물, 정식일, 파일명, 보고서 노출 여부)만 가지고 `FARM_SAMPLES[키]`를 조회하여 화면에 출력한다.
- **주소 맞추기는 순수 함수(`src/domain/farm-preview.ts`):**
  - 시안의 `ADDR` 시·군 매핑 및 해시 기반 거리 계산 공식을 `farmMatch(addr)` 순수 함수로 구현한다.
  - 입력 주소에 포함된 시·군에 따라 가장 가까운 관측 지점 및 거리를 계산하고, 일치하는 곳이 없으면 안내 문구를 표시한다.
- **자료 상자(`MetaBox`) 연동:**
  - 입력된 주소 매칭 지점(기본 춘천 101, 태백시 입력 시 태백 216)에 따라 `getPageMeta("my-farm", station)`로 실시간 연동한다.
- **파일 올리기는 껍데기만:**
  - 실제 파일 업로드나 CSV 내용 파싱은 일절 하지 않는다.
  - 파일 선택 시 파일 이름만 표시하고, "예시 파일로 보기" 클릭 시 시안의 정적 보고서(4개 통계 그리드, 4~8월 관수 막대그래프, 캐릭터 팁 말풍선)를 보여 준다. "다시 올리기"를 누르면 처음 상태로 리셋된다.
- **하지 않는 것:**
  - DB 마이그레이션, 로그인/인증, 실제 파일 저장, 다른 화면(홈, 물, 온도, 햇빛) 수정 등은 포함하지 않는다.
