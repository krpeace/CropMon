# 0012. 단기예보를 10곳 모두 받는다 (물6)

- 날짜: 2026-10-25
- 상태: 확정

## 결정

- **예보 수집 지점을 춘천 1곳에서 10곳 모두로 늘린다** (2026-10-25 사용자 승인). 수집기(croplib-dp)는 지점마다 같은 일을 하므로 코드는 그대로이고, DB 사전 값 `stations.has_forecast`만 켠다 (`supabase/migrations/20261025010000_forecast_all_stations.sql`). 테이블 구조는 그대로라 계약 버전은 v1.3.
- **11/04 공개 판단 전에 기록을 쌓는다.** 10/25에 켜면 11/04까지 열흘치 수집 기록이 생긴다. 지점이 늘면 실패할 곳도 늘기 때문에 일찍 켜서 확인한다.
- **정확도 근거는 아직 춘천뿐이다.** 예보 일사 계수와 예보 오차표는 춘천 자료로 맞춘 값이다. 나머지 9곳은 FAO-56 기본 일사 계수(S1)와 춘천 오차표를 빌려 쓴다. 그래서 물 화면 ②에 "이 지점의 예보 범위(빠르면·늦으면)는 춘천 값을 빌려 써서 아직 검증 전이에요"를 적는다 (`FORECAST_CALIBRATED`). 지점별 계수는 cropwater 연구로 맞춘 뒤 croplib-dp `data/`에 더하고, 이 목록에 지점을 더한다.
- **되돌리기:** SQL Editor 에서 `update public.stations set has_forecast = (stn_id = '101');` 한 줄.
- 예보가 실패한 지점·날은 결정 0011 의 "어제까지 관측 기준" 문구로 보인다.
