# 0024: 다크모드 (시안 v0.3.0, 이슈 #15)

- 날짜: 2026-10-29
- 상태: 확정

## 배경

휴대폰 브라우저의 "자동 다크"가 색을 임의로 뒤집어 화면이 어색하게 보였고, 내 농장에는 색이 직접 박힌 곳이 있었다. 시안 v0.3.0 의 `[data-cmt="dark"]` 값으로 사이트 전체에 다크모드를 넣는다.

## 결정

1. **`<html data-theme>` 하나로만 판단한다.** 미디어 쿼리로 직접 칠하면 버튼으로 고른 선택이 이기지 못한다. 다크 값은 라이트 토큰과 같은 변수 이름을 덮어써서, 화면 코드는 토큰 이름만 쓴다. `color-scheme` 도 함께 정해 브라우저 자동 반전을 막는다.
2. **처음 테마 순서**: 저장된 선택(`cropmon-theme`) → 휴대폰·PC 설정 → 라이트. 저장된 선택이 없을 때만 휴대폰 설정 변화를 따라간다. 하얗게 번쩍이지 않도록 `<head>` 의 인라인 스크립트가 그리기 전에 정한다.
3. **`brand` 와 `brand-ink` 분리**: 꽉 찬 버튼·선택 바탕(흰 글자)은 `brand`, 글자·선·옅은 칠은 `brand-ink`. 다크에서 진초록 글자가 안 보이는 문제를 막는다. 라이트에서는 두 값이 같다.
4. **매우 건조(very-dry) 다크 값은 직접 정했다.** 시안에 없어, iOS 다크 빨강을 기준으로 다른 상태 색과 같은 규칙(dot·fg·bg·card)으로 정했다.
5. **로고는 반전 이미지를 만들지 않고** 다크에서만 흰 바탕판(`plate`)으로 감싼다.
6. 범위 밖: 종합표 1b, "시스템 설정으로 되돌리기" 메뉴.
