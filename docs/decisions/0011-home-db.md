# 0011. 종합 화면은 DB 판정 표를 쓴다 (첫1)

- 날짜: 2026-10-25
- 상태: 확정 (0003 의 물 판정 부분을 대체)

## 결정

- **판정 표 하나를 헤더와 종합 화면이 같이 쓴다** (`getStationBoard`). 지점 10곳 × 작물마다 상태, 부족한 물, 관수 시작점, 뿌리층 전체, 작기, 마지막 관측일, 예보(관수 필요까지 며칠, 오늘 다음 3일 판정)와 지점별 갱신 시각을 한 번에 여섯 번 읽어 5분 동안 쓴다.
- **물 카드 = 물 화면 ①과 같은 규칙** (판정 문구 `waterVerdict`, 배지 `todayBadge`).
- **예보가 없는 지점** (지금은 춘천 밖 9곳, 2026-10-25 사용자 결정):
  - 어제까지의 관측 물수지로만 판정하고 앞날을 말하지 않는다. "아직 여유 있어요, 3일 동안 괜찮아요" 대신 "아직 여유 있어요", 숫자 줄 끝에 "· 어제까지 관측 기준".
  - 물 화면에서도 회차가 없으면 같은 문구를 쓴다. 예보 회차가 36시간보다 오래되면 예보로 쓰지 않는다.
  - 전국 표 "앞으로 3일"은 "예보 준비 중".
- **온도·햇빛은 시안 예시 값에 "예시" 표시** (2026-10-25 사용자 결정). 카드는 회색 "예시" 배지, 전국 표는 칸 이름 옆 "예시". 온1에서 DB 값으로 바꾼다. → **바꿈 (결정 0017, 이슈 #22):** "예시" 표시를 떼고 DB 의 적산온도·적산일사를 쓴다.
- **첫 줄 갱신:** 예보 지점은 회차가 끝난 시각과 "02시·17시 단기예보", 그 밖은 ASOS 관측 받은 시각과 "어제까지 관측".
- **자료가 없으면** 물 카드는 회색 "자료 없음"과 이유(자료가 아직 없음 / DB 를 읽지 못함), 전국 표는 회색 "자료 없음" 배지와 빈 게이지.
