# 0036. 햇빛 자료 상자의 '자료 없음'은 sun_daily 실제 줄로 정한다

- 날짜: 2026-11-08
- 상태: 확정 (2026-11-08 사용자 결정)

## 왜

햇빛 화면은 본문과 자료 상자(쪽 제목 옆 갱신 표시 포함)가 서로 다른 기준으로 "자료 없음"을 정했다.

- 본문(`getSunlightView`): DB `sun_daily`에 그 지점 줄이 있는가 (결정 0016).
- 자료 상자(`getPageMeta`): 고정 사전 `stations.ts`의 `measuresSunlight`.

사전 값이 실제 DB 자료와 다르면 본문은 자료가 있는데 자료 상자만 "자료 없음"이거나, 반대로 본문은 "햇빛을 재지 않아요"인데 자료 상자는 일사 관측이라고 적는 어긋남이 생긴다. 사전은 `measures_sunlight`가 비어 있는(`null`, 확인 안 됨) 지점이 많아 어긋날 여지가 크다.

## 결정

- 자료 상자도 `sun_daily`에 이 지점 줄이 있는지(`SunlightView.kind !== "notMeasured"`)로 정한다. 줄이 없으면 자료 상자 전체가 "자료 없음", 있으면 사전 값과 관계없이 자료를 보여 준다.
- `getPageMeta("sunlight", …)`는 네 번째 인자 `measured`(기본 `true`)를 받는다. 사전 값(`measuresSunlight`)은 더 이상 읽지 않는다.
- 읽기에 실패한 경우(`kind = "error"`)는 줄이 있는 것으로 보고, 갱신 시각만 "자료 없음"으로 둔다 (규칙 6).
- 평년 기간은 자료가 있을 때(`kind = "data"`)만 붙인다.

## 범위 밖

- 종합 화면 햇빛 카드의 "(관측 안 함)" 같은 사전 기반 표시(`src/services/home.ts`)는 이번에 바꾸지 않는다. 필요하면 별도 이슈로 다룬다.
- `stations.measures_sunlight` 열과 사전 값 자체는 그대로 둔다 (지역 고르기 등에서 쓴다).
