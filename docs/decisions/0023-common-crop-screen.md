# 0023: 작물 공통(토양 물 상태) 화면 및 시안 대비 결정 (이슈 #36)

- 날짜: 2026-10-28
- 상태: 확정

## 배경

디자인 시안 v0.2.1에서는 작물 고르기 맨 위에 **"작물 공통"**을 기본값으로 두고, 특정 작물을 고르지 않아도 토양의 물 상태(`public.soil_water_daily`)와 적산온도(`public.heat_daily`, `crop_id = 'common'`)를 볼 수 있게 했다. 다만 프로토타입의 가짜 계산(`sim`, `verdict`)을 실제 데이터 계약 v1.5와 맞출 때 시안과 다르게 정해야 하는 6가지 사항이 있어 사용자 확인을 거쳐 확정했다.

## 결정 (시안과 다르게 정한 6가지와 이유)

1. **판정 단계와 문구**:
   - 시안: 작물 공통도 사과·배추처럼 `"관수 필요 / 아직 여유 / 토양 수분 충분 / 과습 경고"` 5코드와 `"오늘 물 주세요"` 문장, `"부족한 물 / 관수 시작점"`을 썼다.
   - 결정: 작물 없이는 관수 시점을 지시할 수 없으므로 **물 고임(`pool`) · 충분(`ample`) · 보통(`fair`) · 건조(`dry`) · 매우 건조(`very_dry`) (+겨울철 `winter`)** 6단계와 **"토양 속 남은 물 N%"**, **"남은 물 / 담을 수 있는 물 (mm)"**로 보여 준다. `very_dry` 색 토큰(`--color-very-dry-*`)만 새로 더하고 기존 작물 상태 토큰은 바꾸지 않는다.
2. **겨울철(12~2월) 판정 제외**:
   - 시안: 1년 내내 쉬지 않고 계산한다.
   - 결정: 12~2월은 언 땅과 낮은 증발로 숫자가 의미 없으므로 `"겨울철"`(`"12~2월은 판정하지 않아요."`)로 표시하고 3월 1일 `Dr = 0`에서 재시작한 DB 값을 읽는다.
3. **앞으로 3일 전망**:
   - 시안: 작물 공통에서도 앞으로 3일 전망과 전국 표 `"앞으로 3일"` 칸을 그린다.
   - 결정: 11/06 공개 일정에는 관측 물수지만 제공하고, 물 화면 ② 카드는 `"작물 공통은 앞으로 3일 전망을 아직 제공하지 않아요."`, 종합 전국 표 칸은 `"—"`로 표시한다. 또한 물 화면 ③ 돌아보기 그래프는 11/06 필수 카드(①·②)와 분리하여 후속 이슈로 나누어 진행한다.
4. **적산온도 기준온도 5℃ 및 단계 1,000 · 2,000 ℃·일**:
   - 시안과 일치하되, DB `public.crops`(`crop_id = 'common'`, `t_base_c = 5`, `gdd_stages = [1000, 2000]`)와 `public.heat_daily`의 값을 계산 없이 그대로 읽는다. 저온요구량 카드는 시안대로 `"작물 공통에서는 저온요구량을 따지지 않아요"`를 보여 준다.
5. **물 화면 카드 안 토양 12종 선택 (`&soil=`)**:
   - 시안: 내 농장 화면에서만 토성을 고르고 물 화면은 양토 고정이다.
   - 결정: 작물 공통은 토성 반영이 핵심이므로 물 화면 ① 카드 안에 **"계산에 쓴 토양: 양토 ▾"** 선택기를 두어 `soil_types` 12종 중 고를 수 있게 하고 주소창에 `&soil=<코드>`(기본값 `loam`이면 생략)로 남긴다. 문헌 보간 추정 토성 3종(`sandy_clay_loam`, `clay_loam`, `sandy_clay`)에는 `"추정값"` 꼬리표와 `Saxton & Rawls (2006)` 안내 문구를 붙인다.
6. **용어 통일 ("토양")**:
   - 시안에서 `"흙"`과 `"토양"`이 섞여 쓰인 곳을 작물 공통 화면에서는 **"토양"**(예: `"토양 속 남은 물"`, `"계산에 쓴 토양"`)으로 통일한다.
