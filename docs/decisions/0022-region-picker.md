# 0022. 지역 고르기(전체 ASOS 지점 검색) 및 데스크톱 1440 최대 폭

- 날짜: 2026-10-28
- 상태: 확정 (이슈 #39, 시안 v0.2.1 반영)

## 배경

- 시안 v0.2.1에서 데스크톱 내용 최대 폭이 `1296px` → `1440px`로 넓어지고, 헤더 선택 줄에 대표 지점 10곳 칩 외에 전체 ASOS 지점을 검색해 고를 수 있는 "지역 고르기" 팝오버(데스크톱)와 바닥 시트(모바일)가 추가되었다.
- 앞서 이슈 #38(결정 0021)에서 기상청 ASOS 105곳(현행 운영 97곳 + 폐지·휴지 보존 8곳)을 DB(`public.stations`)와 화면 지점 사전(`src/infra/stations.ts`)에 반영해 두었다.
- 기존 `parseSelection`과 `getStation`은 대표 10곳(`STATION_IDS`)만 허용해, 대표 밖 지점(예: `212` 홍천)을 고르고 새로고침하면 `101` 춘천으로 되돌아가는 문제가 있었다.

## 결정

1. **현행 운영 ASOS 97곳 선택 허용 (`src/domain/selection.ts`, `src/services/shell.ts`)**:
   - `parseSelection`과 `getStation`은 `isActive: true`인 현행 운영 지점 97곳을 모두 유효한 지점으로 받아들인다.
   - 사전에 없는 번호(예: `999`)나 폐지·휴지 지점(`isActive: false`, 예: `175` 진도(첨찰산), `116` 관악산)은 기본 지점 `101`(춘천)으로 되돌린다.
2. **가나다 정렬·검색·묶기 순수 함수 (`src/domain/selection.ts`)**:
   - `sortStationsKo`: `localeCompare("ko")`로 한글 가나다순(이름이 같으면 지점번호 오름차순) 정렬한다.
   - `filterStations`: `isActive: true`인 지점만 대상으로 지점 이름 포함, 지점번호 앞자리 일치(`String(id).startsWith(q)`), 시·도 이름 포함으로 거른다.
   - `buildRegionSections`: 검색어가 비어 있으면 `"대표 지점 10곳"`(대표 10곳 원래 순서)과 `"전체 ASOS 지점 (가나다순)"`(현행 97곳 가나다순) 두 묶음을 돌려주고, 검색어가 있으면 `"검색 결과"` 한 묶음(가나다순)을 돌려준다.
3. **반응형 헤더 지역 선택 UI (`src/app/_components/shell/SiteHeader.tsx`, `src/app/tokens.css`)**:
   - `--page-max: 1440px`, `--breakpoint-wide: 80rem`(1280px)을 토큰에 둔다.
   - `>= 1280px`(`wide:`): 대표 10곳 칩 옆에 `"지역 고르기 ▾"` 버튼(대표 밖 지점이 선택되면 진초록 `"● 홍천 212 ▾"` 칩)을 두고, 누르면 380px 팝오버(`role="listbox"`)를 연다.
   - `< 1280px`(`wide:hidden`): 대표 10곳 칩을 숨기고 단일 버튼 `"지역 · ● 춘천 101 ▾"`(높이 44px)으로 접는다. 화면 폭 `< 1024px`에서는 바닥 시트(`role="dialog"`, `"지역 고르기"`)를 헤더 바깥(`backdrop-filter` 바깥)에 띄우고, `1024..1279px`에서는 팝오버를 연다.
   - 검색창에서 `ArrowDown`/`ArrowUp`/`Enter`/`Escape` 키보드 조작으로 지점을 고르거나 닫을 수 있다.
4. **대표 10곳 밖 지점의 자동 순환 및 빈 상태 안내**:
   - 종합 화면 자동 전환(`AutoRotate`)은 대표 10곳만 순환한다. 대표 밖 지점이 선택되거나 시트·팝오버가 열려 있으면 타이머를 멈추고 `"대표 지점 밖"`을 표시한다.
   - 대표 밖 지점은 아직 물 계산 시나리오가 없으므로 종합·물·온도 화면에서 `"자료 없음"`과 `"이 지점은 아직 물 계산을 하지 않아요. 가까운 대표 지점을 골라 보세요"`를 보여 준다(수치를 화면에서 꾸며 계산하지 않음).
   - 종합 화면 햇빛 카드는 `measuresSunlight === null`인 지점에 `"(확인 안 됨)"`, `false`인 지점에 `"(관측 안 함)"`을 구분해 적는다.
