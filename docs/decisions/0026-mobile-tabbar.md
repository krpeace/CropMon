# 0026: 휴대폰 하단 탭바 (시안 v0.3.0, 이슈 #15)

- 날짜: 2026-10-29
- 상태: 확정

## 배경

휴대폰(폭 1024 미만)에서는 상단 메뉴 6개가 로고·테마·로그인 사이 좁은 칸에 가로 스크롤로 들어가, 390px 에서 "종합"만 보이고 나머지는 있는지도 알 수 없었다.

## 결정

1. **휴대폰은 하단 탭바, 데스크톱(1024 이상)은 상단 메뉴.** 항목·순서·주소·아이콘은 `pages.ts` 의 `TABS` 를 그대로 쓰고, 새 메뉴나 계산은 없다. 휴대폰 머리말은 로고·테마·로그인만 남긴다.
2. **두 `nav` 의 `aria-label` 을 같은 "메뉴"로 둔다.** 화면에는 둘 중 하나만 보이고(나머지는 `display: none`) 보조기기와 기존 e2e(`getByRole("navigation", { name: "메뉴" })`)가 그대로 동작한다.
3. **`viewportFit: "cover"`.** 없으면 아이폰에서 `env(safe-area-inset-*)` 가 0 이 되어 탭바가 홈 인디케이터에 붙는다. 탭바는 아래 `12px + 안전 영역`, 좌우 `10px + 안전 영역`에 둔다.
4. **시안의 `bottom: 24px` → `12px + 안전 영역`.** 시안의 24 는 아이폰 틀 그림 안의 홈 인디케이터를 포함한 값이다. 실제 웹에서는 안전 영역이 그 역할을 한다. 시안 아래의 가로 막대(134×5)는 기기 그림이라 만들지 않는다.
5. **겹침 순서**: 탭바 z-30 은 머리말(20)보다 위, 지역·작물 시트와 소개 창(40)보다 아래라서 시트가 열리면 탭바를 덮는다.
6. **바닥 여백**: 푸터 아래에 `탭바 높이 + 12 + 24 + 안전 영역`을 두어 "CropMon 소개"가 탭바 위 24px 에 보이게 한다.
7. 범위 밖: 머리말 높이·로고 크기 변경, 스크롤 시 숨김, 내 농장 탭, `themeColor` 가 토글을 따르게 하는 수정.
