# 0002. 시안으로 화면 껍데기를 먼저 만든다

- 날짜: 2026-10-23
- 상태: 확정

## 결정

- Claude Design 시안(`design/prototype/`)이 정답이다. 색·글꼴·간격·배치·문구를 시안과 같게 맞춘다.
- 이번에는 **껍데기**만 만든다: 공통 틀(헤더·지역/작물 선택 줄·바닥글·가운데 창), 쪽 7개의 제목·질문·자료 상자, 종합 화면 첫 줄과 자동 전환. 카드·그래프 같은 본문은 다음 작업이다.
- 데스크톱(1440) 시안을 먼저 맞춘다. 모바일(390) 배치는 다음 PR이다. 그동안에도 폭이 줄면 깨지지 않게 한다.
- 시안의 색·글꼴·간격은 `src/app/tokens.css` 한 곳에 모으고, 화면은 토큰만 쓴다.
- 지역·작물은 주소창 `?st=&crop=`에 남긴다. 링크를 공유하거나 새로고침해도 같은 지역이 보인다.
- 종합 화면은 시안대로 5초마다 지역·작물을 바꾼다. 주소창도 같이 바뀐다 (뒤로 가기 기록은 쌓지 않는다).
- 글꼴은 시안과 같은 Pretendard CDN 주소를 쓴다.
- 밝은 화면만 쓴다. 버전 표시는 package.json 의 0.0.0 을 그대로 쓴다.
- 종합 화면에는 시안대로 자료 상자 대신 "갱신 · 지점 · 자료" 한 줄만 둔다 (규칙 6번은 시안을 따름).
- 홈의 "데이터베이스 연결" 표시는 빼고, 연결 확인은 `/api/health` 에서만 한다.
- 화면 테스트는 Playwright 로 실제 브라우저에서 한다. 자동 검사(CI)에서도 돈다.
- `design/` 은 시안 원본이라 git 에 올리지 않고, 디자인 개발이 끝나면 지운다. Prettier·ESLint 는 이 폴더를 건너뛴다.

## 예시 값에 대해

- 시안은 화면 안에서 물수지·적산온도·적산일사를 직접 계산한다. 이 저장소는 계산하지 않으므로(CLAUDE.md 규칙 1) 그 코드는 옮기지 않았다.
- 이번에 필요한 예시 값은 지역 칩의 "오늘 물 판정" 20개(지점 10 × 작물 2)뿐이다. 시안을 저장소 밖에서 한 번 열어 그 값을 읽어 `src/mocks/stations.ts` 에 고정 값으로 적었다.
