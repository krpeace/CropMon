# 결정 0053: 휴대폰 종합 자동 전환 제거 · 종합 카드 "도매시장" → "시세" (이슈 #164)

- 날짜: 2026-11-19
- 상태: 확정
- 관련 이슈: #164 (순서표 #144의 S6). 결정 0049(맥락 바)를 이어받는다.
- 기준: 모바일 셸 설계 v1.3 3-4, 시안 v0.4 · v0.4.1 (메뉴 이름 "시세")

## 배경

종합 화면은 5초마다 다음 대표 지역으로 저절로 바뀌었다. 휴대폰에서는 읽던 카드가 5초마다 사라지고, 맥락 바(#155)의 지역 캡슐과 화면 값이 계속 어긋난다. 또 메뉴 이름은 "도매시장"에서 "시세"로 바뀌었는데(#145) 종합의 준비 중 카드만 옛 이름이었다.

## 결정

### 1. 자동 전환은 데스크톱 폭(1024 이상, 태블릿 포함)에서만

- **판정은 CSS 숨김이 아니라 타이머 조건이다.** `shouldRunRotation`에 `desktop` 조건을 더했고, 데스크톱 폭이 아니면 다른 조건이 모두 참이어도 `false`다. 그래서 휴대폰에서는 타이머 자체가 돌지 않고 주소(`history.replaceState`)도 화면 지역도 바뀌지 않는다.
- 휴대폰에서는 "n / 10" · "자동 전환 중지/시작" 버튼 · 진행 막대를 **그리지 않는다**(`null`을 돌려줘 자리도 차지하지 않음). 종합 첫 줄은 제목 + 발표 정보만 남는다.
- 폭은 `matchMedia`를 `useSyncExternalStore`로 읽는다. 서버 그리기와 첫 그리기는 "돌지 않음"에서 시작하고, 브라우저에서 폭을 확인한 뒤 켠다. 폭이 바뀌면 따라간다 — 데스크톱 → 휴대폰으로 줄면 돌던 타이머가 바로 취소되고, 넓어지면 다시 돈다.
- 부품은 폭이 바뀌어도 붙어 있다(훅을 모두 부른 **뒤에** `null`). 그래서 사용자가 눌러 둔 "중지"가 폭이 바뀌어도 남는다.
- **기준 폭은 새로 만들지 않고 `src/domain/autohide.ts`의 `DESKTOP_MIN_WIDTH`(1024)를 재사용**하며, 질의 문자열도 이 값에서 만든다. (`BottomSheet.tsx`의 `DESKTOP_QUERY`는 이번 범위 밖이라 그대로 둠.)
- 데스크톱은 그대로다: 5초 · 대표 10곳 · 중지/시작 · "대표 지점 밖" · 시트/팝오버 열림과 탭 숨김 때 쉼. 30분 자료 갱신(`REFRESH_INTERVAL_MS`)은 휴대폰에서도 지금처럼 돈다.

### 2. 종합 카드 이름 "시세"

`HomeBoardClient.tsx`의 준비 중 카드 `label`을 "도매시장" → "시세"로 바꿨다(주석 두 곳 포함). 질문 문구 · 아이콘(`market`) · 주소(`/market`)는 그대로다. `shell.ts`의 "도매시장에 들어온 양(반입량)", `Sheets.tsx`의 "도매시장 가격(aT)"은 메뉴 이름이 아니라 실제 시장 · 자료를 가리키는 말이라 그대로 둔다.

## 시험

- 단위: `desktop: false`이면 `shouldRunRotation`이 `false`(`auto-rotate-state.test.ts`).
- e2e 휴대폰(`home-mobile.spec.ts`): 버튼 · "1 / 10" 없음, 실제 6초 뒤에도 주소 · 제목 그대로, "시세" 카드가 있고 "도매시장" 글자 없음.
- e2e 데스크톱: 기존 자동 전환 시험 그대로 통과, 폭을 390으로 줄이면 멈추고 1440으로 넓히면 다시 돈다(`selection.spec.ts`).
