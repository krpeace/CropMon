# 0029: 작물 공통 ③ 작기 돌아보기 그래프 (이슈 #45)

- 날짜: 2026-10-29
- 상태: 확정

## 배경

물 화면 `crop=common` 에서는 ③ 작기 돌아보기 카드를 통째로 숨기고 있었다. `readCommonView` 는 1/1~오늘의 `soil_water_daily` 줄을 이미 읽으면서도 `season`·`months` 를 비워 넘겼다.

## 결정

1. **처음 안("남은 물 % 선"을 새로 그리기) 대신, 사과·배추 ③ 그래프 틀을 그대로 다시 쓴다.** 지도사가 작물 화면과 같은 방법으로 읽을 수 있게 하려는 것이다. 새 그래프 컴포넌트는 만들지 않고 `SeasonCard`·`seasonChart`·`ChartHover` 에 작물 공통 모드를 더했다.
2. **위 칸은 ETo 선만 그린다.** 작물 공통은 Kc = 1.0 이라 ETc = ETo 이므로 겹쳐 그리지 않는다. 이름은 "기준 증발산" 대신 **"증발 수요"** 로 쓴다. 마른 시기에는 Ks 때문에 실제로 빠진 물이 ETo 보다 적기 때문이다.
3. **아래 칸 기준선은 두 줄이다.** 건조 시작 = `raw_mm`(남은 물 60%), 매우 건조 시작 = 0.7 × `taw_mm`(남은 물 30%). 0.7 × TAW 는 계약서의 판정 경계(30%)를 눈금 자리로 옮긴 **그래프 좌표**일 뿐, 판정을 다시 하지 않는다(상태는 DB 값 그대로). 이 값은 `season-chart.ts` 의 좌표 계산 안에서만 쓴다. 두 기준선 사이는 옅은 주황, 그 위는 옅은 빨강 바탕이다(작물 공통 상태 토큰이라 다크모드에서도 보인다). 점선 모양(긴 점선·짧은 점선)과 글자("건조 시작"·"매우 건조 시작")를 함께 써서 색만으로 뜻을 전하지 않는다.
4. **오른쪽 "남은 물" % 눈금(100%·60%·30%·0%)은 작물 공통에만 넣는다.** 작물은 고갈계수 p 가 달라 관수 시작점이 남은 물 60% 가 아니므로, 사과·배추에 같은 눈금을 넣으면 틀린 말이 된다. 처음에는 "남은 물 %" 머리글도 달았으나 고른 날 꼬리표에 가려져 빼고, 눈금에 `%` 를 직접 적는다.
5. **`winter` 도 휴면기와 같은 회색 음영**으로 칠한다. 그래프 범위는 1/1~오늘이라 1~2월은 음영, 3/1부터 선이 시작된다.
6. **값 상자(결정 0027과 같은 동작)**: 제목 = 날짜 + 상태 이름(DB 값 그대로), 증발 수요(소수 첫째 자리), 비(정수), 부족한 물 "38 mm / 건조 시작 26 mm", 흙 속 남은 물(정수 %). ETc 줄은 없다. 겨울철이면 부족한 물·남은 물 칸에 "겨울철", 줄이 없으면 "자료 없음".
7. **월별 요약표는 ETc·관수 필요 일수 두 칸을 뺀다.** 작물 공통에는 ETc 가 없고, 작물 상태로 세는 "관수 필요 일수"도 맞지 않는다. 칸을 "—" 로 두면 결측으로 읽힐 수 있어 칸 자체를 뺐다. 작물 공통 상태로 날수를 세는 칸은 더하지 않고 다음에 정한다. 합계 계산(`monthlySummary`)은 그대로다.
8. **상태 줄이 없거나 코드를 모르는 날**은 겨울(12~2월)이면 `winter`, 아니면 상태 없음(null)으로 둔다(① 카드와 같은 규칙). 값 상자 배지는 "자료 없음".
9. **② 앞으로 3일**의 "작물 공통은 앞으로 3일 전망을 아직 제공하지 않아요" 안내는 이 결정과 상관없이 그대로 둔다.

## 바뀌지 않은 것

DB·데이터 계약, croplib-dp, 사과·배추 ③ 의 모양·문구. 화면은 계산하지 않고 DB 값을 옮겨 적기만 한다.
