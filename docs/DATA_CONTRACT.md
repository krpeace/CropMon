# 데이터 계약 (DATA_CONTRACT)

계산 저장소(cropwater, Python)가 Supabase에 올리는 자료와, 이 웹이 읽는 자료의 약속입니다. 테이블을 바꾸면 이 문서와 `supabase/migrations/`를 같은 PR에서 고치고 버전을 올립니다.

## 현재 버전: v0 (연결 확인용)

- 지금 있는 테이블은 연결 확인용 `app_health` 하나뿐입니다.
- 작물 물수지 자료를 담는 정식 계약(v1)은 11월 업로드 코드(cropwater)와 함께 만듭니다.

## 테이블

### `public.app_health`

웹이 데이터베이스에 연결되는지 확인하는 용도입니다. 계산 결과는 담지 않습니다.

| 열           | 형식          | 비어 있어도 되나 | 뜻                     |
| ------------ | ------------- | ---------------- | ---------------------- |
| `id`         | `int`         | 아니요 (기본키)  | 행 번호. 지금은 `1`.   |
| `note`       | `text`        | 아니요           | 상태 메모. 지금은 `ok` |
| `updated_at` | `timestamptz` | 아니요           | 행을 만든 시각         |

- 권한: 행 단위 보안(RLS)을 켜 두었습니다. 비회원(`anon`)과 회원(`authenticated`)은 **읽기만** 할 수 있습니다.
- 만드는 파일: `supabase/migrations/20261022000000_app_health.sql`
