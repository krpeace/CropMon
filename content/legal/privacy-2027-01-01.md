## CropMon 개인정보처리방침

주식회사 파모스(이하 "회사")는 CropMon 서비스(이하 "서비스")를 운영하면서 「개인정보 보호법」에 따라 회원의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위해 이 처리방침을 둡니다.

### 1. 개인정보를 처리하는 목적
회사는 다음 목적으로만 개인정보를 처리하며, 목적이 바뀌면 미리 알리고 필요한 경우 동의를 받습니다.
1. **회원 관리**: 소셜 계정으로 회원 확인, 로그인 유지, 만 14세 이상 확인, 탈퇴 처리
2. **내 농장 서비스 제공**: 회원이 입력한 농장 정보와 관수 기록으로 토양 수분 판정·전망 계산과 표시
3. **서비스 개선과 통계**: 특정 회원이나 농장을 알아볼 수 없게 익명처리(집계)한 자료로 계산식 개선과 통계 작성(8번 참고)
4. **안전한 운영**: 부정 이용 방지, 오류 확인, 보안 사고 대응, 법령상 의무 이행

### 2. 처리하는 개인정보 항목과 수집 방법
회사는 회원과의 서비스 이용계약 체결·이행(「개인정보 보호법」 제15조 제1항 제4호)과 법령상 의무 준수(같은 항 제2호)를 위해 다음 개인정보를 처리합니다.

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 회원 정보(필수) | 소셜 계정 회원 번호, 이름 또는 별명, 이메일 주소(소셜 계정이 제공하는 경우), 가입한 소셜 계정 종류 | 회원이 고른 소셜 계정(카카오·네이버·구글)이 회원 동의를 받아 회사에 제공 |
| 확인 기록(필수) | 확인한 약관·처리방침 판, 확인 시각, 만 14세 이상 확인 시각 | 가입 확인 화면 |
| 내 농장 정보(서비스 이용 시) | 농장 주소, 주소의 좌표, 법정동 코드, 계산에 쓰는 기상청 지점, 흙의 종류, 관수 면적, 필지 번호(입력한 경우), 농장 이름 | 회원 입력(주소를 넣으면 좌표·법정동 코드·기상청 지점은 자동으로 정함) |
| 작기·관수 기록(서비스 이용 시) | 작목·작형, 재배 방식, 작기 시작·끝 날짜, 관수 날짜, 관수량, 메모 | 회원 입력 |
| 계산 결과 | 농장별 토양 수분 계산 값과 판정·전망 | 서비스가 생성 |
| 화면 설정 | 화면 구성(메뉴 순서·사용 여부), 화면 모드 | 회원 설정 |
| 자동 생성 정보 | 접속 일시, 접속 IP 주소, 브라우저·기기 정보, 방문 화면 기록(개인을 식별하지 않는 방문 통계) | 서비스 이용 중 자동 생성 |

- 회사는 기기의 위치(GPS)를 수집하지 않습니다. 농장 위치는 회원이 입력한 주소로만 정합니다.
- 회사는 민감정보와 고유식별정보(주민등록번호 등)를 처리하지 않습니다.

### 3. 처리·보유 기간
| 항목 | 보유 기간 |
|---|---|
| 회원 정보, 확인 기록, 내 농장 정보, 작기·관수 기록, 계산 결과, 화면 설정 | **회원탈퇴 때까지.** 탈퇴하면 운영 데이터베이스에서 바로 파기 |
| 소셜 로그인 뒤 가입 확인을 마치지 않은 계정의 정보 | 로그인 후 24시간 이내 자동 파기 |
| 재해 복구용 암호화 백업 사본 | 백업한 날부터 **최대 7일**. 탈퇴한 회원의 정보도 이 기간 동안 암호화된 백업에 남은 뒤 자동 파기 |
| 백업에서 복구할 때 탈퇴 회원을 다시 지우기 위한 탈퇴 계정 내부 번호(되돌릴 수 없게 바꾼 값으로 개인을 직접 알아볼 수 없는 번호)와 탈퇴 일시 | 탈퇴한 날부터 7일 |
| 서버 실행 기록(접속 IP, 브라우저·기기 정보) | 위탁 서비스(Supabase, Vercel)의 보관 기간에 따라 최대 30일 이내 자동 파기 |
| 방문 통계 | 개인을 식별하지 않는 집계 값만 남음(방문자 구분용 값은 24시간 안에 폐기) |

### 4. 개인정보의 파기 절차와 방법
1. 보유 기간이 끝나거나 처리 목적을 이룬 개인정보는 지체 없이 파기합니다.
2. 전자 파일은 복구할 수 없는 방법으로 지웁니다. 회원탈퇴 시 운영 데이터베이스에서 회원 정보를 지우면 그 회원의 농장 정보, 관수 기록, 계산 결과가 함께 바로 지워집니다. 암호화된 백업 사본에 남은 정보는 접근이 통제된 상태로 보관되다가 최대 7일 안에 자동으로 지워집니다.
3. 회원탈퇴를 해도 소셜 계정(카카오·네이버·구글)의 "연결된 서비스" 목록에는 CropMon이 남아 있을 수 있습니다. 이 연결은 각 소셜 계정의 설정 메뉴에서 직접 해제할 수 있습니다.
4. 회사는 종이 문서로 개인정보를 보관하지 않습니다.

### 5. 개인정보의 제3자 제공
회사는 회원의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우는 예외로 합니다.

### 8. 통계 작성과 연구를 위한 익명처리
1. 회사는 계산식 개선과 통계 작성을 위해 관수 기록과 농장 정보를 특정 회원이나 농장을 알아볼 수 없도록 익명처리(집계)하여 이용할 수 있습니다.
2. 익명처리할 때는 이름, 이메일, 소셜 계정 회원 번호, 회원·농장 고유번호, 농장 주소, 좌표, 필지 번호, 농장 이름, 메모를 모두 빼고, 지역(기상청 지점 또는 시·군), 작목·작형, 흙의 종류, 관수 면적 구간 등으로 묶어 집계합니다. 회원·농장과 다시 이어 볼 수 있는 번호나 대응표는 만들지 않습니다.
3. 이렇게 만든 통계 자료는 특정 회원을 알아볼 수 없으므로 개인정보가 아니며, 회원이 탈퇴해도 지우지 않습니다.
4. 회사는 가명정보를 처리하지 않습니다. 가명정보를 처리하게 되면 이 처리방침을 바꾸어 미리 알립니다.

### 9. 정보주체와 법정대리인의 권리·의무와 행사 방법
1. 회원은 언제든지 자기 개인정보의 열람, 정정, 삭제, 처리정지를 요구하거나 회원탈퇴를 할 수 있습니다.
2. 서비스 안에서 바로 할 수 있는 것:
   - 회원 정보 보기: 사용자 메뉴 "회원 정보"
   - 내 농장 정보·관수 기록 고치기와 지우기: 사용자 메뉴 "농장 설정", 관수 기록 화면
   - 회원탈퇴(모든 회원 자료 삭제): 사용자 메뉴 "회원탈퇴"
3. 그 밖의 요구는 13번 개인정보 보호책임자에게 서면, 전화, 이메일로 하면 지체 없이 처리합니다.
4. 법정대리인이나 위임받은 사람을 통해서도 요구할 수 있으며, 이 경우 「개인정보 처리 방법에 관한 고시」 별지 제11호 서식에 따른 위임장을 내야 합니다.

### 10. 만 14세 미만 아동
회사는 만 14세 미만 아동의 회원가입을 받지 않습니다. 만 14세 미만 아동의 정보가 수집된 사실을 알게 되면 지체 없이 파기합니다.

### 11. 개인정보의 안전성 확보 조치
회사는 「개인정보 보호법」 제29조에 따라 다음 조치를 하고 있습니다.
1. 접근 제한: 데이터베이스의 모든 회원 표에 행 단위 보안(본인 자료만 읽고 쓸 수 있게 함)을 적용합니다.
2. 권한 최소화와 인증 강화: 관리용 키는 서버의 비밀 저장소에만 두고, 화면 코드와 공개 저장소에 두지 않습니다. 관리자 계정에는 2단계 인증을 적용하고 접속 기록을 정기적으로 점검합니다.
3. 전송 구간 암호화: 모든 통신은 암호화(HTTPS)합니다.
4. 기록 관리: 계산 작업의 실행 기록에는 회원·농장을 알아볼 수 있는 정보를 남기지 않습니다.
5. 백업 암호화: 회원 자료 백업은 암호화하여 관리자만 접근할 수 있는 비공개 저장소에 최대 7일 동안 보관합니다.
6. 비밀번호 미보관: 회사는 비밀번호를 받지 않고 소셜 계정으로만 로그인합니다.

### 12. 자동으로 수집하는 장치의 설치·운영과 거부
1. 회사는 로그인 상태를 유지하기 위해 쿠키를 씁니다. 쿠키를 막으면 로그인이 필요한 기능을 쓸 수 없습니다.
2. 화면 모드와 화면 구성 같은 설정은 회원의 기기(브라우저 저장소)에 저장할 수 있습니다.
3. 방문 통계에는 쿠키를 쓰지 않고 개인을 식별하지 않는 방문 통계 도구(Vercel Web Analytics)를 씁니다. 회사는 맞춤형 광고를 위한 행태정보를 수집하거나 제공하지 않습니다.
4. 쿠키 거부 방법: 쓰는 웹 브라우저의 설정 메뉴(예: Chrome 설정 > 개인정보 및 보안 > 서드 파티 쿠키)에서 쿠키 저장을 허용하거나 거부할 수 있습니다.
